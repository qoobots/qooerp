## 五、认证授权流程架构图

```mermaid
sequenceDiagram
    participant Client as 客户端<br/>Vue 3
    participant Gateway as API Gateway<br/>:8000
    participant Auth as qooerp-auth<br/>:8001
    participant Permission as qooerp-permission<br/>:8082
    participant User as qooerp-user<br/>:8084
    participant Redis as Redis 缓存
    participant DB as PostgreSQL

    Note over Client,DB: === 登录认证流程 ===
    
    Client->>Gateway: POST /api/auth/login<br/>{username, password, captcha}
    Gateway->>Auth: 转发登录请求
    Auth->>Auth: 验证验证码 (CaptchaService)
    Auth->>User: Feign: 查询用户信息
    User->>DB: SELECT user
    DB-->>User: 用户信息
    User-->>Auth: 用户信息
    Auth->>Auth: 密码校验 (BCrypt)
    Auth->>Auth: 生成 JWT Token (TokenService)
    Auth->>Redis: 存储 Token (Access + Refresh)
    Auth->>DB: 记录登录日志 (LoginLogService)
    Auth-->>Client: {accessToken, refreshToken, userInfo}

    Note over Client,DB: === 后续请求鉴权流程 ===
    
    Client->>Gateway: GET /api/xxx<br/>Header: Authorization Bearer {token}
    Gateway->>Auth: 校验 JWT Token
    Auth->>Redis: 查询 Token 有效性
    Redis-->>Auth: Token 有效
    Auth-->>Gateway: 鉴权通过
    
    Gateway->>Permission: 查询用户权限
    Permission->>Redis: 查询权限缓存
    Redis-->>Permission: 权限列表
    Permission-->>Gateway: 权限信息
    
    Gateway->>Gateway: 路由到目标微服务
```
